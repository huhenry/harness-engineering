## 安装

```bash
./init.sh
```

`init.sh` 应该是一次干净检出唯一需要跑的命令，跑完这个文件里的其他内容才
能用。等它装上真实依赖之后，运行 `make check`（同时跑 `make test` 和
`make lint`）确认环境是真的能用，而不只是装上了。

## 会话生命周期

会话开始时，先读 `PROGRESS.md` 和 `feature_list.json` 再动手改代码——它们
是"已经做了什么、下一步是什么"的权威来源。

会话结束时，把这两份文件都更新一遍，给接手的下一个会话写好
`session-handoff.md`，并且在结束前走一遍 `clean-state-checklist.md`。
